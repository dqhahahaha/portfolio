质控案例：Gate② 发现的实际问题

🔴 P1: IF 子串匹配 Bug（18 处）

根因：使用期刊名字串匹配 JCR IF，导致 'Neurology' 子串误匹配到 12.0（实际 Neurology Neuroimmunology ≈ 8.2）。

修复：改为期刊全名精确匹配 + 人工核查。影响 9 篇 Neurology 子家族期刊、5 篇 Ophthalmology 子家族。

🔴 P2: 研究类型标注错误（3 处）

  • PMID 32629363：Review → Cohort（121 例国际队列，非综述）
  • PMID 42036830：Review → Cohort（44 例对照研究）
  • PMID 38018493：Cohort → Case Series（标题明确为 Case Series）

🔴 P3: 摘要汉化模板化（127 篇全部重写）

问题：Gate② 发现中文摘要全部为模板格式 + 英文粘贴，非真正汉化。

修复：127 篇全部重写为纯中文摘要，每篇 80-115 字，覆盖背景/方法/结果/结论，数字与 PubMed 原文严格一致。

关键设计决策

  • 3 级灵敏度而非单一检索式：兼顾查全与查准，避免遗漏（如 NMPA 条件性批准路径的 Phase 2 研究）
  • OCEBM 证据等级标注：每篇标注 Level 1-5，便于快速定位高质量证据
  • IF 全名精确匹配：消除子串误匹配，确保数据可信度
  • PMID 全量验证 + Gate 多轮审计：Gate①→②→④ 逐轮收紧标准，而非一次性检查后即交付
  • 双格式交付（XLSX + MD）：XLSX 供深度分析，MD 供快速查阅与版本比对
