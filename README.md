# 丁晴 · 医学情报 × AI系统设计

个人作品与方法论展示页。用公开、可追溯的方法呈现医学证据检索、疾病领域情报与产品竞争分析。

在线访问：[个人主页](https://dqhahahaha.github.io/portfolio/)

## 内容

- **[多数据库文献检索方法](demos/literature.html)**：问题结构化、数据库专用检索、标准化去重、筛选交接与质量闸门
- **[疾病领域知识检索方法](demos/domain-intelligence.html)**：宽搜扩展、试验解析、五层产品身份、权利方追溯与人工校审
- **[JS207 × NSCLC 产品竞争 Dashboard](demos/js207.html)**：以我方产品为锚点，按治疗场景呈现直接竞品、研发进展、资产权利方、监管状态与可验证来源
- **流感氏界 AI 产品运营**：从知识库维护到内容策略与效果复盘

## v1.2 更新

- 为竞品补充监管状态，并区分临床试验状态、申报/审评状态和上市批准状态，避免把“III期”误写成“已申报”或“已获批”。
- 监管信息以 NMPA/CDE、FDA、ClinicalTrials.gov 等一手公开来源为主；每条结论可回到对应页面核验。
- 将大学或医院申办方与实际研发厂家、许可方分开表达，保留资产权利关系和证据链。
- 上线 literature-search 与疾病领域知识检索两套方法论页面，并补充测试结果、适用边界和质量闸门。

完整版本记录见 [更新日志](log.md)。

## 技术

纯静态 HTML，可托管于 GitHub Pages。方法页为自包含文件；JS207 Demo 保持原有公开演示依赖。

## 声明

本页面公开方法与 Demo 不包含企业内部信息、私有脚本、凭据或内部数据。监管状态与医学适用性均按页面标注的数据截止日理解；指南、共识和内部治疗路径仍需由相应医学信息/知识库责任方持续维护。
